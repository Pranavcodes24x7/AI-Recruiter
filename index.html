Mathematical & Algorithm Spec

Weighted Jaccard Similarity Formula

The matching engine does not treat all skills equally. Recruiter evaluation assigns weights to match categories:
• Skills (e.g. AI/ML, DevOps): Weight = 1.5
• Technologies (e.g. PyTorch, React): Weight = 1.2
• Languages (e.g. Python, TS): Weight = 1.0

Match Score = (∑ w_i * matched) / (∑ w_i * required) * 100

Zero-Key Extraction Engine

To satisfy the "No LLM API Key" recruitment constraint, this page executes high-performance client-side token regex matching. Terms are tokenized, processed to ignore sentence punctuation, and scanned using boundary-aware regular expressions.
